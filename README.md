# KitthanetCoding

## 📚 โปรเจคล่าสุด: รายชื่ออุปนิษัท (Upanishads) ทั้งหมด 200+ บท

โปรเจคนี้รวบรวมรายชื่ออุปนิษัท (Upanishads) ทั้งหมด 200+ บท พร้อมคำแปลหัวข้อไทยและจัดทำเป็นไฟล์ PDF ที่สวยงาม

### 🎯 จุดเด่น
- **รวบรวมครบถ้วน**: อุปนิษัท 200+ บท
- **แปลไทย**: ชื่อและความหมายเป็นภาษาไทย
- **จัดหมวดหมู่**: แยกตามประเภทและเวท
- **PDF สวยงาม**: อ่านง่าย ค้นหาได้

### 📁 ตำแหน่งไฟล์
```
upanishads_collection/
├── 📄 upanishads_collection_200_thai.pdf  (ไฟล์หลัก)
├── 📊 ข้อมูลอุปนิษัท JSON
├── 🐍 สคริปต์ Python สำหรับสร้าง PDF
└── 📖 คู่มือการใช้งาน
```

### 🚀 วิธีใช้งาน
```bash
cd upanishads_collection
python generate_upanishads_pdf.py
```
