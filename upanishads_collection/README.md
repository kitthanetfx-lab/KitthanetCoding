# รายชื่ออุปนิษัท (Upanishads) ทั้งหมด 200+ บท พร้อมคำแปลหัวข้อไทย

## 📚 เกี่ยวกับโปรเจค

โปรเจคนี้รวบรวมรายชื่ออุปนิษัท (Upanishads) ทั้งหมด 200+ บท พร้อมคำแปลชื่อเป็นภาษาไทยและคำอธิบายสั้นๆ จัดทำเป็นไฟล์ PDF ที่สวยงามและใช้งานง่าย

## 🎯 จุดมุ่งหมาย

- รวบรวมข้อมูลอุปนิษัทอย่างครอบคลุม
- จัดหมวดหมู่ตามประเภทและเวท
- แปลชื่อเป็นภาษาไทยเพื่อความเข้าใจ
- สร้าง PDF ที่อ่านง่ายและค้นหาได้

## 📋 เนื้อหาที่รวบรวม

### สถิติการจัดหมวดหมู่
- **อุปนิษัทหลัก (Principal)**: 17 บท
- **เวทานตะ (Vedanta)**: 37 บท  
- **โยคะ (Yoga)**: 32 บท
- **ศิวะ (Shaiva)**: 19 บท
- **รอง (Minor)**: 18 บท
- **วิษณุ (Vaishnava)**: 18 บท
- **ศักติ (Shakti)**: 13 บท
- **ปรัชญา (Philosophy)**: 9 บท
- **สันยาส (Sannyasa)**: 7 บท
- **พิธีกรรม (Ritual)**: 7 บท
- **มนตระ (Mantra)**: 5 บท
- **และอื่นๆ**: 18 บท

### การจัดหมวดตามเวท
- **Krishna Yajur Veda**: มากที่สุด
- **Atharva Veda**: รองลงมา
- **Rig Veda**: บทสำคัญหลายบท
- **Sama Veda**: เน้นดนตรีและการสวด
- **Shukla Yajur Veda**: อุปนิษัทสำคัญบางบท

## 📁 โครงสร้างโปรเจค

```
upanishads_collection/
├── data/
│   ├── upanishads_complete.json      # ข้อมูลอุปนิษัทครบถ้วน
│   └── upanishads_basic.json         # ข้อมูลตัวอย่าง
├── src/
│   ├── create_upanishads_data.py     # สคริปต์สร้างข้อมูล
│   └── generate_pdf.py               # สคริปต์สร้าง PDF
├── output/
│   └── upanishads_collection_200_thai.pdf  # ไฟล์ PDF ผลลัพธ์
├── fonts/                            # โฟลเดอร์สำหรับฟอนต์ (หากต้องการ)
├── requirements.txt                  # รายการ package ที่ต้องการ
└── .gitignore                       # ไฟล์ที่ไม่ต้องการใน git
```

## 🚀 วิธีใช้งาน

### 1. ติดตั้ง Dependencies

```bash
cd upanishads_collection
pip install -r requirements.txt
```

### 2. สร้างข้อมูลอุปนิษัท

```bash
python src/create_upanishads_data.py
```

### 3. สร้างไฟล์ PDF

```bash
python src/generate_pdf.py
```

### 4. ดูผลลัพธ์

ไฟล์ PDF จะถูกสร้างที่: `output/upanishads_collection_200_thai.pdf`

## 📖 คุณสมบัติของ PDF

- **หน้าปกสวยงาม**: พร้อมชื่อและคำอธิบาย
- **สารบัญ**: จัดหมวดหมู่และสถิติ
- **เนื้อหาหลัก**: อุปนิษัทแยกตามหมวดหมู่
- **ภาคผนวก**: ความรู้เพิ่มเติมเกี่ยวกับอุปนิษัท
- **รองรับภาษาไทย**: แสดงอักษรไทยได้ถูกต้อง
- **ค้นหาได้**: สามารถค้นหาข้อความใน PDF ได้

## 🗂️ รายละเอียดข้อมูล

สำหรับแต่ละอุปนิษัท มีข้อมูลดังนี้:
- **ลำดับที่**: เรียงลำดับ 1-200
- **ชื่อสันสกฤต**: ชื่อต้นฉบับ
- **ชื่อไทย**: การถ่ายทอดเสียงเป็นไทย
- **ความหมาย**: คำแปลหัวข้อ/ความหมาย
- **หมวดหมู่**: จัดประเภทตามเนื้อหา
- **เวท**: เวทที่อุปนิษัทสังกัด

## 🔧 การปรับแต่ง

### เพิ่มข้อมูลอุปนิษัท
